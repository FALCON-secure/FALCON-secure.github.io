# FALCON project page

Source of the project page for *Secure Agentic Coding through
Counterexample-Grounded Feedback*. The code, the Claude Code plugin, and the
experiments are in [FSoft-AI4Code/FALCON](https://github.com/FSoft-AI4Code/FALCON).

The page is plain HTML (`index.html`) with its figures, the demo video, and the
paper under `assets/`. GitHub Pages serves it from the `main` branch.
